# SkillCraft Machine Learning Internship

## Overview

This repository contains the Machine Learning projects completed as part of the SkillCraft Technology Internship Program. The tasks focus on applying machine learning algorithms to solve real-world problems using Python and popular data science libraries.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* OpenCV
* Jupyter Notebook

---

## Task 1: House Price Prediction

### Objective

Implement a Linear Regression model to predict house prices based on property features such as square footage, number of bedrooms, and number of bathrooms.

### Concepts Covered

* Data Preprocessing
* Feature Selection
* Linear Regression
* Model Evaluation
* Regression Metrics

### Dataset

House Prices - Advanced Regression Techniques (Kaggle)

---

## Task 2: Customer Segmentation using K-Means Clustering

### Objective

Create a K-Means clustering algorithm to group customers of a retail store based on their purchasing behavior.

### Concepts Covered

* Unsupervised Learning
* Customer Segmentation
* K-Means Clustering
* Data Visualization
* Cluster Analysis

### Dataset

Mall Customer Dataset

---

## Task 3: Cats vs Dogs Image Classification using SVM

### Objective

Implement a Support Vector Machine (SVM) model to classify images of cats and dogs from the Kaggle dataset.

### Concepts Covered

* Image Processing
* Feature Extraction
* Support Vector Machines (SVM)
* Classification
* Computer Vision Fundamentals

### Dataset

Dogs vs Cats Dataset (Kaggle)

---

## Task 4: Hand Gesture Recognition

### Objective

Develop a machine learning model capable of identifying and classifying different hand gestures from image or video data.

### Concepts Covered

* Computer Vision
* Image Classification
* Gesture Recognition
* Feature Extraction
* Human-Computer Interaction

### Dataset

Hand Gesture Recognition Dataset
